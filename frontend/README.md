# CloudPlay Frontend

The React 19 + Vite frontend for CloudPlay.

See root [README.md](../README.md) for full platform documentation, game listings, and setup instructions.

## Scripts

- `npm run dev` - Start Vite dev server
- `npm run build` - Compile production bundle with Vite
- `npm test` - Run physics test suite via Node test runner
- `npm run lint` - Run Oxlint code analysis
- `npm run preview` - Preview production build locally
